About me

I'm Anas Amoo, a software engineer and web developer building modern, responsive, and user-friendly applications that solve real problems.

I work primarily with HTML, CSS, JavaScript, Node.js, Express and MySQL, alongside Python, PHP and C. I focus on writing clean, maintainable code — code that works, not just code that looks good.

I'm especially drawn to tech for good: the role technology can play in healthcare, education, food security and public services, particularly across Africa. Every project I build is a chance to learn, solve something real, and ship it.

I'm continuously sharpening my engineering skills and looking for freelance work, internships and full-time roles where I can learn, contribute and grow.
